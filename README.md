# mg-front

Frontend del juego musical (React + TypeScript + Vite).

```
npm install
npm run dev      # http://localhost:5173
```

Requiere el backend (mg-back) corriendo en http://localhost:8080.
En desarrollo, Vite reenvía `/api/*` al backend, así que no hace falta CORS.

El micrófono solo funciona en `localhost` o HTTPS.
